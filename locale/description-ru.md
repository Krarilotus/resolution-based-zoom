# Resolution Based Zoom

Включите масштабирование по разрешению. В игре используйте E для приближения и Ctrl+E для отдаления. При использовании Custom Hotkeys проверьте предложенные сочетания Ctrl+колёсико в разделе «Настройки > Горячие клавиши». Также можно выбрать разрешение меню при выходе с карты.
